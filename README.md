# Tabasco Tourism - Guide & Explorer

An interactive, responsive, and visually stunning web platform designed to promote tourism in **Tabasco, Mexico** for international visitors and travelers.

This platform was developed as a capstone collaborative project under the **English Access Scholarship Program (Access)**, funded and supported by the **U.S. Embassy in Mexico**.

---

## 🎯 Project Vision & Context

This project was created to encourage international travelers to explore the southeastern region of Mexico—specifically the natural, historical, and cultural wealth of the state of Tabasco.

Through this platform, users can explore travel options, find lodging, discover typical cuisine, and plan their activities, all presented in high-quality, professional English.

---

## ✨ Features & Modules

- **Home Portal (`home.html`)**: An immersive welcome screen showcasing key statistics, intro videos, and highlights of Tabasco's nature, culture, gastronomy, and traditions.
- **Interactive Navigation & Travel Guide (`how-to-get-there.html`)**: Travel routes, transport cost estimators, and duration comparisons (flights, buses, driving) from Mexico's main transit hubs to Tabasco.
- **Destination Explorer (`what-to-do.html`)**: Responsive catalog highlighting Tabasco’s waterfalls, museums, magical towns, and ecological reserves.
- **Gastronomy Hub (`where-to-eat.html`)**: Curated selection of traditional dishes (like *pejelagarto* and *cacao* products) with origin tags and recommended local dining spots.
- **Accommodation Guide (`where-to-stay.html`)**: Curated lodging recommendations classified by experience (nature, business, family) with direct links for booking.
- **Interactive Planner (`plan-your-trip.html`)**: Accordion-based FAQ portal addressing safety, weather, currency, and health tips.
- **Collaboration Showcase (`students-proyects.html`)**: A portal linking to custom external micro-sites created by fellow students highlighting specific locations like Comalcalco, Centla, and Tapijulapa.

## 🛠️ Technical Stack & Development Process

This project is built from scratch utilizing clean, semantic web technologies with a focus on high-performance loading speeds, responsive behaviors, and micro-interactions.

*   **Frontend Core**: Semantic HTML5 & CSS3 (Custom Variables, Flexbox, CSS Grid, custom keyframe animations, responsive media queries).
*   **Interactions**: Vanilla JavaScript (ES6) for the dynamic carousel, FAQ accordion state management, responsive navigation, and lazy-loading image patterns.
*   **Design & Typography**: Curated typography (Playfair Display & DM Sans) and HSL-tailored color palettes reflecting Tabasco’s jungle and cacao heritage.
*   **Version Control**: Managed via Git and GitHub to resolve merge conflicts, track progress, and review contributions.

### Development Methodology

1.  **Requirement Gathering & Localization**: Analysed the needs of English-speaking international travelers. Selected key regional landmarks (cacao farms, biosphere reserves) and localized cultural contexts.
2.  **UI/UX Design**: Structured wireframes focusing on a clean, modern, nature-inspired theme (jungle green and chocolate gold accents) with smooth micro-animations.
3.  **Component Architecture**: Developed reusable modular styles for headers, footers, image credit badges, and card systems.
4.  **Collaboration & Git Workflow**: Established a team workflow to merge separate modules, align coding patterns, and ensure cross-browser compatibility.
